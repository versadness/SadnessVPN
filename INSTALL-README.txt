Sadness VPN — Windows Installer · BETA

Требования: Windows 10/11 x64 (Windows 10 2004 или новее), .NET Framework 4.8.
В поддерживаемых выпусках Windows .NET Framework уже входит в ОС.
Если он повреждён или отключён, установщик покажет сообщение о недостающем компоненте.
Electron, Python, sing-box, Mihomo и AmneziaWG включены в установщик.
WebView2 отдельно не требуется. XHTTP обслуживает Mihomo, Xray больше не используется.

Откройте MSI, нажмите Install и подтвердите запрос администратора.
Для обновления 3.0.4 до 3.0.5 закройте клиент (включая трей) и выполните:
msiexec /i "SadnessVPN-3.0.5-Setup-x64.msi" REINSTALL=ALL REINSTALLMODE=vomus
После установки используйте ярлык Sadness VPN на рабочем столе или в меню Пуск.
Не переносите отдельно EXE из папки runtime: запускайте корневой SadnessVPN.exe.

Диагностика доступна без открытия VPN: Пуск → Sadness VPN → Diagnostics.
Журналы: %LOCALAPPDATA%\SadnessVPN\data\diagnostics
launcher.log — запускатель и целостность файлов;
startup-python.log — ранние ошибки бэкенда Python;
application.log — работа интерфейса и VPN.
Если профиль недоступен: %TEMP%\SadnessVPN-diagnostics.
Вторая попытка запуска MSI позволяет восстановить или удалить программу.
MSI ведёт установочный журнал в TEMP (Msi*.log); его путь также доступен
в свойстве MsiLogFileLocation. Для явного пути: msiexec /i <файл.msi> /L*V <журнал.log>

Личные серверы, подписки и настройки НЕ включены в установщик.
На этом же ПК приложение использует существующий профиль пользователя.
Удаление программы сохраняет профиль и журналы. Удаляйте личные данные отдельно,
только если они больше не нужны. Перед удалением выключите автозапуск в приложении.

Безопасность: пакет не отключает Defender, не добавляет исключения и не меняет
настройки SmartScreen. Zapret/WinDivert входят в комплект и запускаются только
при включении пользователем. Неиспользуемые служебные BAT-файлы не включены.
Программа и MSI пока не имеют доверенной цифровой подписи издателя.
SmartScreen может показывать предупреждение неизвестного издателя; установщик
сам по себе не исправляет репутацию файла. Отключать защиту не рекомендуется.
Если показано именно название вируса/угрозы, остановите запуск и передайте
название обнаружения разработчику. Ничего не восстанавливайте из карантина автоматически.
