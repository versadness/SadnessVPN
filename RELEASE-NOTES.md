# Sadness VPN 2.0.17 Beta

**Предварительная тестовая сборка — не стабильный релиз.**

## Установка

Скачайте `SadnessVPN-2.0.17-Beta-Setup-x64.msi` из Assets ниже и запустите его.
Не скачивайте Source code для установки приложения.
Windows 10 2004+/Windows 11 x64, .NET Framework 4.8+, права администратора.
Python, WebView2 и ядра включены. Пакет чистый: добавьте свою подписку.
Внутри приложения номер `2.0.17`; эта поставка имеет статус **Beta**.

## Что изменилось в бета 2.0.17

- Переход на MSI: установка в Program Files, ярлыки, восстановление и удаление.
- Отдельный запускатель и проверка целостности компонентов.
- Журнал ранних ошибок до загрузки основного интерфейса.
- Ярлык Diagnostics в меню Пуск для проверки без запуска VPN.
- Исключены неиспользуемые BAT-файлы и резервные копии; UPX отключён.
- Сохранены XHTTP/Reality, Mihomo, sing-box, Xray, WireGuard/AmneziaWG и маршрутизация приложений.

## Проверено

159 модульных тестов, 23 backend-регрессии; запуск с пустым профилем,
установка, восстановление отсутствующего Python DLL и удаление/повторная установка на ПК разработчика.
Четыре файла личного профиля сохранены после удаления, целостность 1033 файлов комплекта проверена.
На независимом чистом ПК эта бета ещё требует проверки.

## Известные ограничения

- Нет доверенной цифровой подписи: SmartScreen может предупреждать о неизвестном издателе.
- Переход на MSI не устраняет предупреждения о репутации. Защиту Windows не отключайте.
- Возможны ошибки; работоспособность всех серверов и конфигураций не гарантируется.
- Диагностика: Пуск → Sadness VPN → Diagnostics.

Для отчёта используйте Issues. Не публикуйте ключи, ссылки подписок и неочищенные журналы.
