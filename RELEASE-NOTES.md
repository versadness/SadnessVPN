# Sadness VPN 2.0.18 Beta

## Hysteria 2

- `hy2://` и `hysteria2://`, обычные и Base64-подписки, Clash YAML.
- Исправлен стандартный URI с `/` после адреса, IPv6 без явного порта, user:password и percent-encoding.
- TLS/SNI, ALPN и Salamander. Проверка сертификата по умолчанию включена.
- Port hopping, pinSHA256 и расширенные YAML-параметры направляются на Mihomo в режиме «Авто»; sing-box 1.10.7 не получает неподдерживаемые параметры.
- HY2 использует свой мультиплексор, не общий smux. В маршрутизации отображается QUIC.
- Gecko, ECH и Realm пока не поддерживаются этой сборкой; явная ошибка вместо молчаливого игнорирования.

## Обновление без переустановки

Если установлена **MSI-версия 2.0.17**, отключите VPN, закройте клиент и откройте
`SadnessVPN-2.0.17-to-2.0.18-Beta-Update-x64.msp` (около **8,4 МиБ**).
Нажмите **Update**, подтвердите права администратора. Удалять приложение не нужно.
Подписки, настройки, HWID и ярлыки сохраняются. Python, WebView2 и ядра повторно не включаются в патч.
Это локальное обновление по двойному нажатию, не автоматическая загрузка обновлений внутри клиента.

Для нового компьютера используйте полный `SadnessVPN-2.0.18-Beta-Setup-x64.msi` (около 434 МиБ).
MSP не устанавливает приложение с нуля и не обновляет старую portable-версию.
Если ранее использовалась portable, закройте её и установите MSI; не запускайте обе версии одновременно.
Полный MSI предназначен для новой установки, для уже установленной 2.0.17 используйте именно MSP.
Windows 10 2004+/11 x64 и .NET Framework 4.8+. Python, WebView2 и VPN-ядра включены в полный установщик.

## Проверки

- 169 модульных тестов, 9 регрессий подписок.
- Реальные локальные HY2-соединения через встроенные sing-box и Mihomo: без obfs, Salamander, сертификатный pin; неверные пароль и pin отвергаются.
- UI-регрессия на трёх размерах окна: без JavaScript-ошибок.
- Патч применён к установленной 2.0.17: Windows Installer показывает 2.0.18, 1033 файла проверены по SHA-256; пять файлов профиля сохранены.
- Неизменённые большие зависимости сохранили содержимое и идентификаторы файлов.
- Повторное применение, штатное удаление MSP и повторное обновление прошли успешно.
- Запуск установленной 2.0.18 подтверждён состоянием приложения и журналом готовности окна.

Внешний HY2-сервер пользователя не проверялся; доступность зависит от сети и разрешённого UDP.
TCP-пинг в списке серверов не является проверкой HY2/QUIC; отсутствие ответа на него не доказывает недоступность HY2.
Это **Beta**, не стабильный релиз. Доверенной подписи пока нет, предупреждение SmartScreen возможно.
Защиту Windows не отключайте. При ошибке: Пуск → Sadness VPN → Diagnostics.
В публичных Issues не публикуйте ссылки подписки, пароли, ключи, HWID и полные неочищенные журналы.
