Sadness VPN Runtime 2.0.17 — устанавливается через MSI
====================

1. Полностью распакуйте архив в отдельную папку.
2. Запустите SadnessVPN.exe.
3. Подтвердите запрос прав администратора — они нужны для VPN-драйвера и Zapret.

Установка не требуется. Не запускайте SadnessVPN.exe прямо из архива: рядом с ним
должна оставаться вся папка _internal. В неё включён WebView2 Runtime.

Настройки и подписки хранятся отдельно в профиле Windows пользователя:
%LOCALAPPDATA%\SadnessVPN\data

Автономный интерфейс со встроенным WebView2 Runtime x64.
Windows 10/11 x64, локальная папка. Не запускайте из сетевой папки/UNC.
Устанавливать Edge, WebView2 или Python отдельно не нужно.
Повторный запуск открывает работающий экземпляр. Крестик завершает приложение.
При включённом «Тихом запуске» окно скрывается после загрузки интерфейса;
для открытия используйте значок трея или повторный запуск ярлыка.

AmneziaWG использует весь ПК и DNS из .conf. Маршрутизация отдельных процессов,
локальные прокси и Gemini DNS относятся к TUN/WireGuard, не к нативному AWG.
Для смены сетевых настроек сначала отключите VPN.

Настройки → Диагностика: копирование сохранённой истории, до 4 МБ.
Файлы журнала: %LOCALAPPDATA%\SadnessVPN\data\diagnostics.
WebView2 Fixed Version входит в архив и не устанавливается в систему.
Для обновлений безопасности встроенного движка используйте свежие версии Full Portable.
Архив чистый: в нём нет серверов, подписок, личного HWID, ключей или настроек автора.
На новом ПК первый запуск пустой: добавьте собственную подписку или конфиг.
Если Sadness VPN уже запускался под этим пользователем Windows, приложение откроет
его существующий профиль из %LOCALAPPDATA%. Это не данные из portable-архива.
Серверы разделены на сворачиваемые группы подписок. Ручные серверы идут отдельно.

Настройки → Ядро: Авто / sing-box / Mihomo / Xray · XHTTP.
В режиме Авто VLESS + XHTTP использует Xray с sing-box для TUN и правил приложений.
Из ссылки автоматически читаются Reality, путь, режим XHTTP и JSON extra,
включая XMUX и отдельный канал скачивания downloadSettings.
Если ссылка требует allowInsecure без отпечатка сертификата, Авто использует
Mihomo, если он поддерживает её параметры. Проверка сертификата никогда не
отключается автоматически для исправных защищённых ссылок.
После обновления старой подписки дополнительные параметры загрузятся заново.
В маршрутизации отображаются протокол/транспорт, Reality и маршрут приложения.
«Сейчас» — соединения, обнаруженные ядром; «По правилу» — ожидаемый маршрут,
а не подтверждение трафика. Неопознанные процессы не выдаются за обнаруженные.
Версии дополнительных ядер: Mihomo 1.19.30, Xray 26.3.27.
Лицензии и ссылки на исходники: _internal\bin\licenses.

2.0.16: исправлены ложные ERROR при определении процесса и проверка автозапуска.
Пинг подключения измеряет HTTP-ответ через VPN-ядро; при тайм-ауте показывает «—».
