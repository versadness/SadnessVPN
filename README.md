# Sadness VPN

Исходники настольного клиента Sadness VPN и Android-приложения.
Настольная версия этой ветки — **3.4.9 Beta**, Android имеет отдельную нумерацию.

[Выпуски и установщики](https://github.com/versadness/SadnessVPN/releases)

## Windows

Для обычной установки используйте `SadnessVPN-3.4.9-Setup-x64.exe` из выпуска.
EXE содержит полный MSI. Отдельный MSI — альтернативный установщик той же
версии. Перед обновлением полностью завершите приложение, включая трей.
Пользовательский профиль хранится отдельно в `%LOCALAPPDATA%/SadnessVPN/data`.

MSP-патчи предназначены только для базовой версии, указанной в имени файла.
Выпуск 3.4.9 содержит прямые патчи с 3.4.3, 3.4.4, 3.4.6, 3.4.7 и 3.4.8.
Контрольные суммы установщиков и патчей опубликованы в `SHA256SUMS.txt`.

Выпуск доступен для ручной установки. Подписанный автоматический канал
обновлений остаётся отдельным процессом публикации.

## Разработка и проверки

Настольный интерфейс работает в Electron, локальный API и управление движками
реализованы на Python. Сборочное окружение использует Python 3.11 и Node.js;
для Windows MSI/MSP также необходимы Windows SDK и системный компилятор C#.
Зависимости описаны в `requirements.txt` и `package-lock.json`. Сторонние
движки, драйверы и геобазы из локального каталога `bin` в Git не включены.

Из корня проекта:

```powershell
.\venv311\Scripts\python.exe -m unittest discover -s tests -t . -q
node --test tests/electron-audit.test.cjs
.\venv311\Scripts\python.exe tools/build_candidate.py --base 3.4.8 --notes installer/release-notes-3.4.9.json
```

Параметр `-t .` при unittest включает изоляцию пользовательского профиля.
Живые локальные тесты протоколов находятся в `tools/test_*_live.py` и
`tools/test_*_loopback.py`; установочные тесты действительно меняют
установленную программу и запускаются отдельно.

Ключи подписи, пользовательские данные, рабочие конфигурации доступа и готовые
пакеты не должны попадать в историю исходников. Сборка кандидата сама по себе
не публикует выпуск.
