## Что нового в 3.0.9

- Исправлена главная причина безымянных ошибок подключения: маршруты на исчезнувший из подписки сервер безопасно переводятся на основной VPN.
- Приложения, правила, их порядок, ID и состояние сохраняются; потерянный сервер никогда автоматически не превращается в маршрут напрямую.
- Ошибки пользовательской конфигурации теперь возвращают HTTP 422 и записывают понятную причину в журнал вместо безымянного HTTP 500.
- Восстановлено копирование журнала и локального ID в буфер обмена. Остальные разрешения Chromium по-прежнему запрещены.
- Интерфейс показывает одно уведомление о восстановлении маршрутов, основной маршрут и действие **«Исправить»**, если изменения не удалось записать на диск.
- Сообщение лаунчера при обычном первом запуске больше не выглядит как ошибка.
- Актуализированы проверки модального редактора правил и доступности элементов на маленьком окне; результаты сохраняются даже при падении теста.

Подробности и проведённые проверки перечислены на [странице релиза 3.0.9](https://github.com/versadness/SadnessVPN/releases/tag/v3.0.9-beta).

## Возможности

- Раздельные группы серверов и подписок.
- VLESS, XHTTP, TLS/Reality, Shadowsocks, Trojan, Hysteria 2, WireGuard и AmneziaWG — в пределах возможностей сервера и ядра.
- sing-box для большинства подключений, Mihomo для XHTTP, сложного Hysteria 2 и маршрутов через разные серверы; отдельное ядро AmneziaWG.
- TUN и локальные SOCKS5/HTTP-порты.
- Маршрутизация по приложениям, доменам, GeoSite, GeoIP и IP-CIDR.
- Одновременное назначение разных серверов разным приложениям.
- AI-DNS, Zapret, статистика, журнал и встроенная проверка обновлений.
- Стеклянный интерфейс Electron, прозрачность и выбор акцентного цвета.

## Установка и обновление

1. Используйте Windows 10/11 x64.
2. Отключите VPN и полностью закройте клиент, включая значок в трее.
3. Скачайте `SadnessVPN-3.0.9-Setup-x64.exe` только из Assets официального релиза.
4. Запустите файл и подтвердите системный запрос, если доверяете источнику.
5. После установки запускайте Sadness VPN через созданный ярлык.

Профиль пользователя хранится отдельно:

```text
%LOCALAPPDATA%\SadnessVPN\data
```

Подписки, правила и настройки не входят в публичный установщик.

## Проверка загрузки

- Файл: `SadnessVPN-3.0.9-Setup-x64.exe`
- Версия: **3.0.9.0**
- Размер: **188 992 535 байт**
- SHA256: `9cc55af94700332c5914409da478c23bcc2ebf281c3c363b269a556b19bad9d0`

Проверка в PowerShell:

```powershell
Get-FileHash -LiteralPath '.\SadnessVPN-3.0.9-Setup-x64.exe' -Algorithm SHA256
```

Совпадение SHA256 подтверждает соответствие опубликованному файлу, но не заменяет цифровую подпись. Установщик пока не подписан сертификатом издателя, поэтому SmartScreen может показать предупреждение «Неизвестный издатель».

## Если возникла ошибка

[Создать Issue](https://github.com/versadness/SadnessVPN/issues/new)

Укажите версию Windows, версию Sadness VPN, шаги воспроизведения, ожидаемый результат и приложите скриншот. При проблемах подключения укажите протокол, транспорт и выбранное ядро, если они известны.

Журналы:

```text
%LOCALAPPDATA%\SadnessVPN\data\diagnostics
```

**Issues публичные. Не публикуйте ссылки подписок, UUID, приватные ключи, пароли, HWID и полные конфиги.** Перед отправкой журнала удалите личные данные и адреса серверов.

Не отключайте Defender и не добавляйте исключения ради запуска. Если защита сообщает об угрозе, прекратите запуск и приложите название обнаружения к Issue.
