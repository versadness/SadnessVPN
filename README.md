## Возможности бета-версии

- Подписки с раздельными группами серверов.
- sing-box, Mihomo и Xray; VLESS + XHTTP, TLS и Reality.
- Автоматический выбор ядра: XHTTP через связку Xray + sing-box.
- WireGuard и нативный AmneziaWG.
- Маршрутизация по приложениям, сведения о протоколе, транспорте и Reality.
- Встроенные стратегии Zapret для тестирования доступности Discord/YouTube.
- Настраиваемый фон и аватар, работа с треем.
- MSI с восстановлением компонентов и отдельной диагностикой запуска.

## Требования и установка

1. Windows 10 версии 2004 или новее / Windows 11, **x64**. Для ARM64 эта бета не проверена.
2. .NET Framework 4.8 или новее. Обычно уже включён в поддерживаемую Windows; при его отсутствии установщик сообщит об этом.
3. Закройте предыдущую версию клиента, скачайте MSI и запустите установку.
4. Подтвердите запрос прав администратора, если доверяете источнику. Права необходимы для сетевых компонентов.
5. Откройте **Sadness VPN** через ярлык и добавьте собственную подписку или конфигурацию.

**Python, WebView2 и VPN-ядра уже включены.** Отдельно устанавливать Python или браузер Edge не нужно. Подписка на VPN не включена: пакет не содержит серверов, ключей или настроек разработчика.

Версия внутри приложения отображается как `2.0.17`; статус этой поставки — **Beta**, независимо от числового обозначения в окне.

## SmartScreen и цифровая подпись

**Бета-пакет пока не подписан доверенным сертификатом издателя.** Windows SmartScreen может показать «Неизвестный издатель» / «Windows защитила ваш компьютер». Это предупреждение о репутации приложения, а не само по себе обнаружение вируса.

Мы не рекомендуем отключать Defender или SmartScreen и не добавляем исключений. Если Windows сообщает конкретное название угрозы, прекратите запуск и сообщите название обнаружения в Issues. Не восстанавливайте файлы из карантина автоматически.

Сертификат не гарантирует отсутствие предупреждения у новой сборки. Подробнее: [официальная документация Microsoft](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation).

## Если бета не запускается

Откройте **Пуск → Sadness VPN → Diagnostics**: проверка работает отдельно от основного интерфейса.

Журналы находятся в `%LOCALAPPDATA%\SadnessVPN\data\diagnostics`:

| Файл | Что проверять |
| --- | --- |
| `launcher.log` | Отсутствующие компоненты, запуск процесса, готовность окна |
| `startup-python.log` | Ранние ошибки Python/.NET/WebView |
| `application.log` | Работа интерфейса и VPN |

Если папка профиля недоступна, проверяйте `%TEMP%\SadnessVPN-diagnostics`.
Установочный журнал: `%TEMP%\Msi*.log`. Повторный запуск MSI предлагает **Repair** (восстановить) или **Remove** (удалить).

## Обратная связь по бета-тесту

[Сообщить об ошибке](https://github.com/versadness/SadnessVPN/issues/new?template=bug_report.md)

Укажите версию Windows, версию клиента, выбранное ядро, шаги воспроизведения и ожидаемый результат. Для начала достаточно скриншота ошибки и нескольких относящихся к ней строк журнала.

**Issues публичные. Не публикуйте ссылки подписок, UUID, приватные ключи, пароли, HWID и полный конфиг.** Проверьте журналы вручную: в них могут оставаться имена пользователя, пути, адреса серверов и посещённых ресурсов. Не прикрепляйте их целиком без удаления личных данных.

## Данные и удаление

Профиль хранится отдельно от программы: `%LOCALAPPDATA%\SadnessVPN\data`.
Обновление и удаление MSI сохраняют профиль. Перед удалением отключите VPN и автозапуск в приложении. Личные данные удаляются отдельно только по решению пользователя.

## Статус репозитория

Это репозиторий **бета-дистрибутивов, документации и сообщений об ошибках**. Исходный код клиента здесь пока не опубликован. Лицензии сторонних компонентов и ссылки на их исходники находятся в установленном комплекте `runtime\_internal\bin\licenses`.

Не используйте бета-версию как единственный инструмент для критически важных подключений. Используйте программу в рамках правил вашей сети и применимого законодательства.
