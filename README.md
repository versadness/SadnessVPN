## Что нового в 3.0.4

- **Настоящая версия в журнале запуска.** Раньше лаунчер всегда писал `Launcher 2.0.24`. Теперь номер подставляется при сборке из того же источника, что и версия приложения, устраняя путаницу при диагностике.

Также включены исправления **3.0.3**:

- Исправлен невидимый значок в системном трее — иконка теперь входит в пакет приложения.
- Исправлена читаемость списка выбора сервера в маршрутизации: устранён светлый текст на белом фоне системного списка.

### Ранее в 3.0.2

- **Новый главный экран:** кнопка подключения без подложки по центру, под ней переключатели, ниже скорость и таймер; в нижнем ряду — сервер, режим и внешний IP.
- **Исправлен таймер сессии:** счётчик больше не идёт вдвое быстрее реального времени.
- **Исправлены флаги стран:** вместо букв `de`, `fi` и других кодов в подписи сервера отображается флаг, без зависимости от поддержки эмодзи-флагов шрифтами Windows.
- **Gemini DNS переименован в AI-DNS.**
- Включённые переключатели и выбранный сервер теперь заметно подсвечиваются.
- Плитки скорости и карточки сервера, режима и IP упрощены и выровнены по центру.
- В развёрнутом окне содержимое главного экрана центрируется по вертикали.

Список изменений предоставлен разработчиком. При публикации проверены версия MSI, размер и SHA256; функциональное тестирование сборки не проводилось.

## Возможности

- Подписки с раздельными группами серверов.
- Несколько VPN-ядер, включая sing-box, Mihomo и Xray.
- VLESS, XHTTP, TLS/Reality и Hysteria 2; доступность конкретных параметров зависит от ядра и сервера.
- Маршрутизация по приложениям и пользовательским правилам.
- Стеклянное оформление, настройки интерфейса и работа с системным треем.

## Установка и переход с предыдущих версий

1. Используйте Windows x64. Сборки для других платформ здесь не опубликованы.
2. Отключите VPN и полностью закройте предыдущий клиент, включая экземпляр в трее.
3. Сохраните резервную копию настроек, подписок и правил.
4. Скачайте MSI по ссылке выше и запустите установщик. Подтверждайте системные запросы только если доверяете источнику.
5. Запускайте приложение через созданный установщиком ярлык.

**Для 3.0.4 опубликован полный MSI.** Старые MSP-патчи ветки 2.0.x не предназначены для установки 3.0.4. Совместимость обновления поверх каждой предыдущей версии при публикации не проверялась. Если установщик сообщает о конфликте версий, не удаляйте данные и не применяйте случайные параметры MSI — сообщите об ошибке.

Для установленной **3.0.3** доступно встроенное обновление: **Настройки → Обновления → Beta → Проверить обновления**, затем скачать и установить. На сервере опубликован патч **3.0.3 → 3.0.4** (около 86 МиБ). Он не подходит для 3.0.2 и более ранних версий. Автоматическая проверка выполняется один раз при запуске; ручная кнопка доступна отдельно.

Не запускайте напрямую внутренний исполняемый файл бэкенда: он не является пользовательским ярлыком приложения.

## Проверка загрузки

- Файл: `SadnessVPN-3.0.4-Setup-x64.msi`
- Версия внутри MSI: **3.0.4**
- Размер: **219 230 208 байт**
- SHA256: `e330a5984012f0620a6dd1db29fed6ae7386ae2e4e1bafbf9a4176a98f2cf028`

Проверить скачанный файл в PowerShell:

```powershell
Get-FileHash -LiteralPath '.\SadnessVPN-3.0.4-Setup-x64.msi' -Algorithm SHA256
```

Совпадение SHA256 подтверждает соответствие опубликованному файлу, но не заменяет проверку безопасности.

## Если возникла ошибка

[Сообщить об ошибке](https://github.com/versadness/SadnessVPN/issues/new)

Укажите версию Windows, версию клиента, шаги воспроизведения, ожидаемый результат и приложите скриншот. При проблемах подключения укажите протокол и выбранное ядро, если они известны.

Для установок, сохраняющих профиль ветки 2.x, журналы находятся в `%LOCALAPPDATA%\SadnessVPN\data\diagnostics`. Если в новой сборке путь отличается, используйте раздел журналов приложения или путь, указанный в сообщении об ошибке.

**Issues публичные. Не публикуйте ссылки подписок, UUID, приватные ключи, пароли, HWID и полные конфиги.** Перед отправкой журнала удалите личные данные, адреса серверов и другую чувствительную информацию.

Не отключайте Defender и не добавляйте исключения ради запуска. Если защита сообщает об угрозе, прекратите запуск и приложите название обнаружения к сообщению об ошибке.
