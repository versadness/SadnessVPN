## Что нового в 3.0.5

- **Исправлен XHTTP с разными адресом сервера и SNI.** XHTTP переведён на Mihomo и проверен на проблемном сервере реальной передачей HTTPS-трафика.
- **Xray удалён.** Он больше не используется клиентом и не входит в новую сборку. Обновление очищает только устаревший файл внутри установленного Sadness VPN.
- Автовыбор направляет XHTTP и сложные конфигурации Hysteria 2 в Mihomo, остальные совместимые серверы — в sing-box.
- Внутренний порт Clash API выбирается динамически, уменьшая конфликты с другими программами.
- Добавлена диагностика повторных ошибок статистики и поднятого туннеля без передачи данных.
- Уменьшен объём служебных WebSocket-сообщений интерфейсу.
- Настройки, серверы, маршруты, WireGuard, Zapret, оформление и системные операции разделены на самостоятельные модули бэкенда.
- Устранены дублирующиеся источники состояния портов, выбранного сервера и профилей.
- Исправлена версия лаунчера в журнале и свойствах файла: теперь показывается 3.0.5.
- Добавлен однофайловый Setup.exe с иконкой приложения и проверкой встроенного MSI.

Полный список изменений, проверок и контрольные суммы находится на [странице релиза 3.0.5](https://github.com/versadness/SadnessVPN/releases/tag/v3.0.5-beta).

## Возможности

- Подписки с раздельными группами серверов.
- VLESS, XHTTP, TLS/Reality, Shadowsocks, Trojan, Hysteria 2, WireGuard и AmneziaWG — доступность зависит от параметров сервера и выбранного ядра.
- sing-box для большинства подключений, Mihomo для XHTTP, сложного Hysteria 2 и индивидуальных маршрутов; отдельное ядро AmneziaWG.
- TUN, локальные SOCKS5/HTTP-порты и маршрутизация по приложениям.
- Одновременное назначение разных серверов отдельным приложениям и пользовательским правилам.
- AI-DNS, Zapret, журнал, статистика, подписки и встроенная проверка обновлений.
- Стеклянный интерфейс Electron, настройки прозрачности и акцентного цвета.

## Установка и обновление

1. Используйте Windows 10/11 x64.
2. Отключите VPN и полностью закройте предыдущий клиент, включая экземпляр в трее.
3. Для обычной установки запустите `SadnessVPN-3.0.5-Setup-x64.exe` и подтвердите системный запрос только если файл скачан из этого репозитория.
4. Подписки, правила и настройки находятся в `%LOCALAPPDATA%\SadnessVPN\data` и при проверенном обновлении 3.0.4 → 3.0.5 сохраняются.
5. После установки запускайте приложение через ярлык Sadness VPN.

Если используете MSI вручную для обновления 3.0.4:

```powershell
msiexec /i ".\SadnessVPN-3.0.5-Setup-x64.msi" REINSTALL=ALL REINSTALLMODE=vomus
```

Python, Electron и VPN-ядра входят в установщик. **WebView2 отдельно скачивать не нужно.**

Проверить файл в PowerShell:

```powershell
Get-FileHash -LiteralPath '.\SadnessVPN-3.0.5-Setup-x64.exe' -Algorithm SHA256
```

Совпадение SHA256 подтверждает соответствие опубликованному файлу, но не заменяет цифровую подпись. Пакеты пока не подписаны сертификатом издателя, поэтому SmartScreen может показать предупреждение «Неизвестный издатель».

## Если возникла ошибка

[Сообщить об ошибке](https://github.com/versadness/SadnessVPN/issues/new)

Укажите версию Windows, версию клиента, шаги воспроизведения, ожидаемый результат и приложите скриншот. При проблемах подключения укажите протокол, транспорт и выбранное ядро, если они известны.

Журналы находятся в `%LOCALAPPDATA%\SadnessVPN\data\diagnostics`.

**Issues публичные. Не публикуйте ссылки подписок, UUID, приватные ключи, пароли, HWID и полные конфиги.** Перед отправкой журнала удалите личные данные, адреса серверов и другую чувствительную информацию.

Не отключайте Defender и не добавляйте исключения ради запуска. Если защита сообщает об угрозе, прекратите запуск и приложите название обнаружения к сообщению об ошибке.
